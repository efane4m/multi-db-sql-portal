# Multi-DB SQL Portal

Прототип веб-приложения для выполнения SQL-запросов к нескольким базам данных с разграничением прав доступа, ролями (Администратор / Пользователь) и кэшированием результатов.

## 🛠 Технологический стек
* **Frontend:** React (Vite), Axios, React Router.
* **Backend:** Python 3.10+, Django, Django REST Framework, SimpleJWT.
* **Базы данных:** PostgreSQL (3 отдельные базы).
* **Кэширование:** Redis (Memurai для Windows).

---

## 📋 Предварительные требования
Перед началом установки убедитесь, что на вашем компьютере установлены:
1. **Python** (версия 3.10 или выше).
2. **Node.js** (версия 18 или выше).
3. **PostgreSQL** (сервер должен быть запущен, желательно наличие pgAdmin).
4. **Redis** (для Windows рекомендуется установить [Memurai](https://www.memurai.com/), он работает как служба и эмулирует Redis на порту 6379).
5. **Git**.

## 🚀 Пошаговая установка

### Шаг 1. Клонирование репозитория
Откройте терминал и склонируйте проект:
```bash
git clone https://github.com/efane4m/multi-db-sql-portal.git
cd multi-db-sql-portal
```

### Шаг 2. Настройка переменных окружения (env)
В корне проекта создайте папку `env` (если ее нет) и внутри нее файл `.env`.
В файл `.env` впишите ваши данные для подключения к PostgreSQL:
```env
DB_USER=postgres
DB_PASSWORD=ваш_пароль_от_postgres
DB_HOST=127.0.0.1
DB_PORT=5432
```
> **Примечание:** файл `.env` добавлен в `.gitignore` и не попадает в репозиторий в целях безопасности.

### Шаг 3. Создание баз данных в PostgreSQL
Откройте **pgAdmin** или консоль `psql` (SQL Shell) под пользователем `postgres` и выполните следующие SQL-команды для создания трех баз данных:
```sql
CREATE DATABASE auth_db;
CREATE DATABASE db_stores;
CREATE DATABASE db_logistics;
```

### Шаг 4. Настройка Бэкенда (Django)
Перейдите в папку сервера:
```bash
cd server
```

Создайте и активируйте виртуальное окружение:
**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```
**Mac/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

Установите зависимости:
```bash
pip install -r requirements.txt
```

Выполните миграции для всех трех баз данных (строго в таком порядке):
```bash
python manage.py migrate --database=default
python manage.py migrate --database=db_stores
python manage.py migrate --database=db_logistics
```

### Шаг 5. Заполнение БД тестовыми данными (Seed Data)
В проекте написан специальный скрипт для быстрого наполнения баз магазинами, продуктами и логистикой. 
Находясь в папке `server` (с активированным venv), выполните:
```bash
python manage.py seed_data
```
*В консоли должно появиться сообщение "Данные успешно добавлены!"*

### Шаг 6. Создание Администратора
Создайте суперпользователя для входа в панель управления:
```bash
python manage.py createsuperuser
```
*(Введите логин, email и пароль. Запомните их!)*

### Шаг 7. Настройка Фронтенда (React)
Откройте **ВТОРОЙ терминал** (не закрывайте первый, где Django) и из корневой папки проекта перейдите в клиент:
```bash
cd client
npm install
```

## 🏃‍♂️ Запуск проекта

Для работы проекта потребуется **три** запущенных процесса.

1. **Redis (Кэш):** Убедитесь, что служба Memurai (или Redis) запущена в фоне (в Windows проверьте в трее или в "Службах").
2. **Терминал 1 (Бэкенд):**
   ```bash
   cd server
   venv\Scripts\activate  # или source venv/bin/activate
   python manage.py runserver
   ```
   *Сервер запустится на `http://localhost:8000`*
3. **Терминал 2 (Фронтенд):**
   ```bash
   cd client
   npm run dev
   ```
   *Сайт будет доступен по адресу `http://localhost:5173`*

## 🧑‍💻 Как пользоваться системой (Инструкция для тестирования)

### 1. Настройка доступов через Админку
1. Откройте `http://localhost:8000/admin/` и войдите под суперпользователем.
2. Перейдите в раздел **Users** -> **Add user**. Создайте пользователя, например `ivan`, задайте пароль.
3. Откройте карточку `ivan` на редактирование:
   * В блоке **Дополнительно** заполните ФИО, Должность.
   * Прокрутите вниз до блока **Database accesses**.
   * Нажмите *Add another Database access*, выберите `db_stores` (Магазины) и сохраните. *Теперь ivan имеет доступ только к базе магазинов.*

### 2. Работа на сайте (Сторона пользователя)
1. Откройте `http://localhost:5173/login`.
2. Войдите под пользователем `ivan`.
3. На странице **Профиль** вы увидите свои данные.
4. Перейдите в **Работа с БД**.
5. Выберите базу `db_stores` и введите тестовый SQL-запрос:
   ```sql
   SELECT s.name AS store, p.name AS product, pr.price 
   FROM stores_price pr
   JOIN stores_store s ON pr.store_id = s.id
   JOIN stores_product p ON pr.product_id = p.id;
   ```
6. Нажмите **Выполнить**. Появится таблица с ценами.
7. **Проверка кэширования:** Нажмите "Выполнить" еще раз. Появится зеленая надпись `(Взято из кэша Redis)`, а данные вернутся моментально.
8. **Проверка безопасности:** Попробуйте выполнить `DELETE FROM stores_store;`. Сервер вернет ошибку `Разрешены только SELECT запросы`.

## ⚠️ Возможные проблемы и их решение
* **Ошибка 500 при выполнении запроса:** Убедитесь, что запущен Redis (Memurai). Если кэш недоступен, сервер выдаст ошибку.
* **Ошибка "relation does not exist":** Вы не выполнили миграции для второстепенных баз. Повторите команды `migrate --database=...` из Шага 4.
* **Не работает авторизация:** Очистите `localStorage` в браузере (F12 -> Application -> Local Storage) и попробуйте войти заново, чтобы получить свежий JWT-токен.
